# Tank Battle for Cardputer-ADV

## 固件描述

**Tank Battle** 是一款专为 **M5Stack Cardputer-ADV** 打造的复古坦克对战游戏。利用 ADV 的 240×135 横屏、全键盘和 TCA8418 键盘控制器，实现流畅的双人同屏对战体验。

游戏采用经典俯视角坦克玩法，包含可破坏的砖墙、不可穿透的钢墙和阻挡子弹的水域地形。支持 **双人对战**（P1 vs P2，无 AI）和 **单人挑战**（玩家 vs AI 敌人）两种模式。

画面使用 M5Canvas 双缓冲渲染，60 FPS 流畅无闪烁；右上角计分牌实时显示双方击杀数与生命值，让你在激烈对战中随时掌握局势。

## 操作说明

### 双人对战模式（2P DUEL）
| 玩家 | 移动 | 开火 |
|---|---|---|
| **P1（绿色坦克）** | `W` `A` `S` `D` | `X` |
| **P2（蓝色坦克）** | 方向键（↑↓←→） | `Enter` |

### 单人模式（1P vs AI）
| 玩家 | 移动 | 开火 |
|---|---|---|
| **P1（绿色坦克）** | `W` `A` `S` `D` | `X` |

### 通用按键
| 按键 | 功能 |
|---|---|
| `Tab` | 暂停 / 继续 |
| `Esc` | 重新开始（游戏结束后） |
| `1` | 切换到单人模式 |
| `2` | 切换到双人对战模式 |
| `X` / `Enter` | 开始游戏 |

## 游戏规则

### 双人对战（2P DUEL）
- 玩家 1 与玩家 2 正面交锋，**场上不生成 AI 敌人**
- 双方各有 **3 点生命值**
- 被对方子弹击中会损失 1 点生命值，同时对方获得 1 个击杀数
- 生命值归零的玩家落败
- 率先取得 **2 次击杀** 的玩家获胜

### 单人模式（1P vs AI）
- 玩家独自对抗 AI 敌人
- 玩家有 **3 条命**，被打光即游戏结束
- 击毁 **20 辆敌方坦克** 即可获胜
- AI 坦克会随机游走，并朝玩家方向射击

### 地形规则
| 地形 | 外观 | 特性 |
|---|---|---|
| 空地 | 黑色 | 可自由通行 |
| 砖墙 | 棕色横纹 | 可被子弹摧毁 |
| 钢墙 | 灰色金属 | 不可摧毁，阻挡子弹 |
| 水域 | 蓝色波纹 | 坦克可穿过，子弹会被阻挡 |

## 技术规格

| 项目 | 参数 |
|---|---|
| 开发板 | M5Stack Cardputer-ADV (ESP32-S3) |
| 显示屏 | ST7789 240×135，rotation 0 = 横屏 |
| 键盘 | TCA8418 I2C 键盘控制器 (地址 0x34) |
| 渲染方式 | M5Canvas 双缓冲，pushSprite |
| 帧率 | 约 60 FPS |
| 固件大小 | 4 MB（合并镜像） |
| 程序占用 | 518,567 字节（Flash 的 39%） |
| RAM 占用 | 28,268 字节（8%） |

### 依赖库
```

M5Cardputer    1.1.1
Adafruit TCA8418 1.0.2
```

### 开发环境
```
Arduino CLI    1.6.0
ESP32 Core     3.3.13
FQBN           esp32:esp32:m5stack_cardputer
```

## 已适配的 Cardputer-ADV 键盘坐标

经过实测确认的按键位置（`keyList()` 返回的 `(x, y)` 坐标）：

| 按键 | 坐标 |
|---|---|
| `W` | (2, 1) |
| `A` | (2, 2) |
| `S` | (3, 2) |
| `D` | (4, 2) |
| 方向键 `↑` | (11, 2) |
| 方向键 `←` | (10, 3) |
| 方向键 `↓` | (11, 3) |
| 方向键 `→` | (12, 3) |
| `Esc` | (0, 0) |

> 注：ADV 的键盘读数由 `TCA8418KeyboardReader` 处理，坐标经过 `remap()` 转换后 `y` 值恒在 0~3 之间。

## 版本说明

### v1.0.0 — 首个完整版本

**新增**
- 双人对战模式（P1 vs P2），无 AI 干扰
- 单人模式（1P vs AI），击毁 20 敌人获胜
- 右上角实时计分牌：显示双方击杀数与生命值
- 完整方向键支持（ADV 专用坐标映射）
- 标题页模式选择（按 `1` / `2` 切换）
- 四种地形：空地、砖墙、钢墙、水域
- 双缓冲渲染，约 60 FPS

**修复**
- 修复空格与回车同时触发开火的问题（现改为 P1 用 `X`，P2 用 `Enter`）
- 修复屏幕显示为竖屏的问题（`setRotation(0)` 才是横屏）
- 修复双人模式仍生成 AI 敌人的问题
- 修正方向键坐标映射（`↑`=(11,2) 而非此前推测的 (13,3)）

**已知限制**
- 仅适配 Cardputer-ADV（`board_M5CardputerADV = 24`）
- 老款 Cardputer 需另行调整按键映射

## 烧录方法

### 方式一：网页烧录（推荐）
1. 打开 burner 网页烧录器
2. 上传 `CardputerAdv_Tank.ino.merged.bin`（4 MB）
3. 用 USB-C 连接 Cardputer-ADV
4. 点击烧录

### 方式二：命令行烧录
```bash
esptool.py --chip esp32s3 --port COMx write_flash 0x0 CardputerAdv_Tank.ino.merged.bin
```

### 方式三：自行编译
```bash
arduino-cli compile \
  --fqbn esp32:esp32:m5stack_cardputer \
  --output-dir ./build \
  ./CardputerAdv_Tank
```
